INSTALLATION (XAMPP / WAMP)
1. Copier le dossier "labconnect" dans htdocs (ou www).
2. phpMyAdmin > Importer > sql/database.sql
3. Vérifier config/database.php (user/password MySQL + BASE_URL)
4. Ouvrir http://localhost/labconnect/setup_admin.php  (crée l'admin) puis SUPPRIMER ce fichier
5. Ouvrir http://localhost/labconnect/login.php
