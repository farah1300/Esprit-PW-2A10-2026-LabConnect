# LabConnect - Medical Analysis Management Platform

## Overview
This project was developed as part of the PW - 2nd Year Engineering Program at **Esprit School of Engineering** (Academic Year 2026–2027).

LabConnect is a web platform that accompanies the patient before, during and after a medical analysis: laboratory search, appointment booking, online results with health follow-up, notifications and complaints.

## Features
- Laboratory search and price comparison
- Appointment booking by time slot (QR code)
- Online results with health evolution tracking
- Automatic e-mail notifications and reminders
- Complaint management
- Home sampling requests

## Tech Stack
### Frontend
- HTML, CSS, Bootstrap, Tailwind CSS, JavaScript

### Backend
- PHP (MVC architecture)
- MySQL

## Architecture
MVC architecture: `Controllers`, `Models`, `Views` (partials, layout, pages), with a Front Office and a Back Office.

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/farah1300/Esprit-PW-2A10-2026-LabConnect.git
   ```
2. Place the project in `htdocs` (XAMPP) and start Apache and MySQL.
3. Import the database from `database/labconnect.sql`.
4. Open `http://localhost/Esprit-PW-2A10-2026-LabConnect/index.php`.
